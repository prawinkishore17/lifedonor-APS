The Life Donor project is a mobile application designed to connect blood donors with recipients in real time through a simple and user-friendly interface. Developed using Android Studio with Kotlin, the application integrates Firebase for authentication and real-time data management, and a map-based system for locating nearby donors and healthcare centers.

Users can register as donors or recipients, manage their profiles, search for required blood groups, and view donor availability on an interactive map. The system supports a request-posting mechanism for blood banks, hospitals, and donation events, with real-time notifications ensuring donors are alerted instantly during urgent needs.

A key feature of Life Donor is its donor recognition and reward system: every verified donation earns points that are tracked on the donor's profile and displayed on a community leaderboard, with annual recognition for top contributors. This incentive structure is designed to encourage sustained, repeat participation rather than one-time donation, addressing a gap in most existing donor apps, which focus on matching but not long-term engagement.

The interface is structured across multiple screens — login/registration, donor/recipient dashboards, request creation, map view, leaderboard, and profile management — prioritizing clarity, responsiveness, and accessibility. This version of Life Donor emphasizes reliable design, essential features, and donor motivation over advanced predictive systems, using proven, lightweight technologies rather than unnecessary computational overhead.
